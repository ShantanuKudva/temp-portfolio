# Work (`/work`) Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `/work` page shell — a wine/burgundy velvet "The Work" page with a featured reel, a drifting reel wall, a real lightbox player (ElasticSlider volume), and a closing CTA — with placeholder media wired for a later drop-in swap.

**Architecture:** A `WorkPage` composes hero → featured → wall → cta, owns lightbox open-state + selected reel, and renders a region-scoped ColorBends signature + page GradualBlur. Reel data lives in `lib/work.ts` (placeholder, `// TODO(real):`). ElasticSlider is a re-skinned Framer-Motion component vendored under `components/`.

**Tech Stack:** Next 16 (App Router), React 19, TypeScript, Tailwind v4, Framer Motion (`motion/react`), three (ColorBends), Vitest + @testing-library/react.

## Global Constraints

- Palette/type locked (verbatim): wine `#5B0F1A`, espresso `#3B2A24`, mocha `#6B4E42`, taupe `#B79E8C`, crème `#F7F3EE`, amber-dot `#D9A05B`; Playfair / Montserrat / Alex Brush. No new brand colors — Work reuses wine + existing tokens. Work surface bg: `linear-gradient(165deg, #5b0f1a 0%, #380710 45%)`.
- Animation stack = Framer Motion (`motion/react`) + Lenis. GSAP not used here.
- React Bits = idea source: re-skin ElasticSlider to wine/crème tokens; never ship the generic look.
- React Compiler safe: no synchronous setState in effects (use rAF / imperative refs); no `Math.random` / `Date.now` in render.
- Reuse existing primitives: `Reveal` (`components/motion/reveal.tsx` — props `children, delay, y, className, as`), `Parallax` (`components/motion/parallax.tsx` — props `children, speed, className`), `GradualBlur` (`components/effects/gradual-blur.tsx` — props `position, target, height, strength, hasFooter`), `CurtainLink` (`components/transition/curtain-link.tsx` — props `href, children, className, ariaLabel`), `ColorBends` (`components/ColorBends.jsx` — props include `colors, speed, rotation, scale, intensity, transparent, noise`), `cn()` (`lib/utils.ts`).
- Git: precise `git add <path>`, never `-A`; leave `.gitmodules`, `skills/`, `public/assets/incoming/` untracked; Co-Authored-By trailer on commits.
